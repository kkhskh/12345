# Manuscript style rules (Path 1)

These rules bind `paper_master.md` and `paper_master.tex`.

1. Plain academic English in connected paragraphs. No slogans, no campaign history, no COR, no obstruction.
2. “Probe-invisible” always means: invariant to this frozen linear board probe’s probability vector, within a stated absolute tolerance.
3. “Causal” refers to a defined residual intervention on the frozen network and a measured change in its output distribution. It does not mean the representation is necessary, sufficient, unique, or complete.
4. Do not write “we are the first.” Do not write “unlike all previous work, we discover causal board representations.”
5. Do not convert \(\Delta Y = 0.0201\) into “a 2.01% improvement.”
6. Distinguish equal L2, equal JS, and equal causal effectiveness.
7. Name official negative letters in the main text when they bound the claim.
8. Mark any number not recomputed from local arrays with a provenance footnote or a table note.
9. Prefer: used, changed, measured, tested, found, estimated, the result did not support.
10. Avoid: groundbreaking, harnesses, delves, sheds light, paves the way, hidden causal substrate, robustly establishes, conclusively proves.
11. Introduce residual stream, nullspace, JS, and \(Y=G-Q\) before using them as a matter of course.
12. Title and abstract stay inside Othello-GPT and this probe.
