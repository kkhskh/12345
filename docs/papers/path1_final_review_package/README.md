# Causal Information Outside a Frozen Board Probe in Othello-GPT — private review package

This package contains the manuscript, the saved result arrays it is based on, and the code that recomputes the paper's numbers, regenerates every table and figure, and checks every number in the text against its source. It is a private package for independent human review. It has not been submitted or published, and it must not be distributed without the authors' authorization.

Path 1 verdict: `PATH1_COMPLETED_WITH_EXPLICIT_EXTERNAL_VERIFICATION_LIMITATIONS`. The reasons are in `FINAL_SCIENTIFIC_VERDICT.md`.

## What the paper claims

The study uses one 8-layer Othello-GPT, one frozen 64-square linear board probe, and residual edits at a single site. The edits lie in the kernel of the probe's class-logit contrasts. Every edit starts from the Editor A reference activation \(h_E\), which is the natural recipient activation \(h_R\) after a probe-space board editor has been applied. The probe's 64×3 probability tensor at \(h_E + t\,\delta\) equals its value at \(h_E\) to roundoff. Output divergence is also measured from \(h_E\). Under these conditions, kernel directions from the intended target's natural activation shift legal-move probability toward the target more than wrong-target and random kernel directions do. At matched output divergence the advantage over wrong targets is \(+0.0266\), with interval \([0.0179, 0.0357]\), on 48 pairs. A ridge map trained only on training games reproduces part of the effect without a target activation at evaluation. The paper also reports the tests that fail: mean scores stay negative, more than half of the map's gain over Editor A is stage-conditioned, target switching fails its preregistered gate, and no visible–kernel interaction is found. The conclusion is limited to this probe. The probe does not exhaust the residual information that affects legal-move outputs. The paper does not claim that the model has a second world model.

## Quick check

From the package root, with Python 3.9 or later, numpy, scipy, matplotlib and pytest:

```
python scripts/verify_paper_claims.py
python scripts/reproduce_figures.py
python -m pytest tests/test_paper_reproducibility.py -q
```

`REPRODUCIBILITY.md` gives versions, the full pipeline, and what each step proves.

## What is not included

- The model checkpoint and the probe weights. Replaying an intervention requires obtaining them separately, as described in `data/README.md`.
- The sealed confirmation split. It was never opened.
- Pair- and triplet-level arrays for the feature-ablation, switching and factorial studies, and for the original board-edit validation. They were searched for and not found. The paper reports those results as archival console values.
