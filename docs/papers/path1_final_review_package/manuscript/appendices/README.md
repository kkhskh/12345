# Appendices

The appendices are part of the single manuscript source, `manuscript/paper_master.md`, under the headings "Appendix A. Definitions and protocol details", "Appendix B. Additional recomputed results" and "Appendix C. Provenance". They are compiled into `manuscript/paper_master.pdf` with the main text.
