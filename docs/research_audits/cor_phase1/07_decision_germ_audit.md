# 07 — Decision germ audit

## 1. Candidate meanings in the project

The same word is used for incompatible objects.

| Meaning | Where | Equivalent to a steering vector? |
|---|---|---|
| Decodable feature | 08c probe, Li–Nanda board decode | NO; decode ≠ causal sufficiency |
| Candidate-specific activation projection `P^c_v φ_v` | Def. 2 | Can be; often is a linear readout |
| Latent-state map `P^y_v φ_v` | Update §5.4, 0B | A fitted decoder |
| Local equivalence class | Suggested by “germ” language; never defined | UNSPECIFIED |
| Sufficient statistic for the decision | Implied by the name; not stated | Would be stronger than a steering vector |
| Causally sufficient state | 08R2 hope; not established | Interchange, not `O` |
| Minimal transferable representation | NST 64-D map | Compact steering map |
| Local object glueable into a global section | Sheaf language | Only after `ρ` is chosen |

The project uses these interchangeably without an equivalence relation. Status: DEFINITION ONLY, overloaded.

## 2. Sufficiency

A germ that determined decisions would require: equal germs imply equal `L_c` under a specified context family and intervention class (observational or interventional).

No such theorem exists. Attack A is a counterexample even observationally: same germs, opposite heads.

Othello: decoder equality is not hidden-state equivalence (fiber SPEC: probe-invisible causal effects). Interchange/full residual patch ≠ germ sufficiency.

## 3. Minimality and uniqueness

No order, no equivalence relation, no uniqueness. Invertible reparameterizations of stalks leave the abstract constraint `ρ s_u=s_v` unchanged but not Euclidean `O`. Irrelevant dimensions can be added. A full activation is a germ (`P=I`). A constant is a germ (`P=0`). Nothing in Def. 2 excludes trivial representations.

Update Proposition 7 (superposition non-uniqueness) already says unique semantic decomposition is not identified. That proposition is a limitation statement, not a uniqueness theorem for germs.
