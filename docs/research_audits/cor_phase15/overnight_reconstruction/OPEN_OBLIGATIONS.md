# Open obligations

These are unresolved. They are not a scheduled Phase 2 and not a promise of a later report beyond this directory.

1. **Exotic branch zeros.** On seed 0, a multi-start search at five radii did not find a non-constant centered edit with branch increment zero. Isolated large-amplitude zeros are not proved absent. If one exists, it is defined by the branch output, which is a partial evaluation of `R`, and it still would not give a budget-B0 bound.

2. **Architectures not differentiated.** Stacks, post-norm, parallel residuals, RMSNorm, rotary scores, multi-query attention, `Q/K/V` biases inside the numeric Jacobian, and trained operating points. The shift identity was not claimed for post-norm. Theorem U uses pre-norm.

3. **Sharpness of `Λ`.** The explicit majorant is valid and about `8.16×10^5` times `||g||` on seed 0. A tighter majorant that stays above `||g||` would not change Theorem L. One was not derived.

4. **Final-normalized blocks.** Only the constant-shift transfer was checked: a further LayerNorm kills `a 1`. The centered response of a final-LN readout was not given its own Lipschitz comparison.

5. **No rates.** Existence counterexamples were not turned into frequencies. A frequency would not create a mechanism.

6. **Phase 2.** Remains NO GO. No protocol in this directory authorizes a refit, a new Othello run, an IOI run, or probe training on evaluation responses.

If this run is interrupted, the checkpoint files `WORK_STATE.md` and `RESEARCH_JOURNAL.md` are the resume point. They should be read against the tests. A claim that is not in `PROOF_REGISTER.csv` is not a result of this package.
