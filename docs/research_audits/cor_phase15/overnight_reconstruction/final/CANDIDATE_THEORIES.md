## Rejected dossier. Finite branch-kernel family

The full specification is in `workstream_5/prediction.md`. The equality `R = 1_{t=r} w·δ` holds when the finite LayerNorm increments lie in the kernels of the branch input maps. On a weight setting built for `δ=(0, 0.45, -0.25, 0.15)` at the read token, `R=0`, while `||g|| ||δ|| = 0.4554966651252395` and `g·δ = 0.1066527641320657`. The certificate is exact and stricter than Cauchy–Schwarz on that point.

It is not a successor. The constant line is already the shift identity. On every seed 0–11 the stacked `Q,K,V` map is injective, so Theorem F leaves no non-constant edit in the family. The extra point is one vector at manufactured weights, and nearby scales leave the family. The content of the equality is that an unread direction is added by the skip. That is the residual equation.

No frozen protocol is issued for this dossier. It was checked mathematically and is not queued as an experiment.

## Strong negative

On this block, a quantity that does not use `R` or `Dm` does not give a non-constant finite constraint tighter than the constant-shift identity and Cauchy–Schwarz, except on a non-generic kernel condition that collapses to the shift identity whenever the branch input map is injective.

Two routes close the generic case.

- Budget B0 excludes branch weights. For every non-constant `δ`, Theorem U exhibits weights with `|R|` arbitrarily large. There is no finite weight-free upper bound.
- Any Lipschitz certificate is at least `||g|| ||δ||` by differentiability (Theorem L). The explicit weight-norm certificate on seed 0 is about `8.16×10^5` times `||g||`.

Direct evaluation returns `R`. The derivative returns the linear term and not the finite remainder. The shift identity returns the finite value on constants only. Nothing else in the examined list returns `sign(R)` for a general centered edit on an open set of weights.
