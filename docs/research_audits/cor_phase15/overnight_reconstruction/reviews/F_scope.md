Same cloud environment. Not an external referee.

**Objection.** One block, random weights, no stack, no post-norm, no RMSNorm, no rotary positions, no trained operating point. A boundary here is not a boundary for language models.

**Resolution.** Agreed. The open list is exactly that. Theorem U uses the pre-norm image being independent of the branch scale; a post-norm block feeds the residual into the normalization and the same scaling argument is not claimed. A stack can route a centered edit through later blocks. Nothing here forbids a future identity on a larger class. Nothing here supplies one.

**Objection.** The search for exotic zeros was 12 restarts. A missed zero would reopen Theorem K on generic weights.

**Resolution.** A missed zero would be an additional exact family at one weight, still defined by the branch output being invariant, which is a partial forward evaluation. It would not be a B0 bound, and it would not undercut Theorem L. The cell stays open because the search is not a proof. It is not a candidate.

**Status.** Scope is one block. Extension is unresolved, not granted.
