# 14 — Cross-examination

The five reviews were separate passes. They disagreed with the first drafts and, on two points, with each other. A disagreement is resolved below only by a narrower theorem or an explicit counterexample. Nothing was kept because the first draft had already been written.

## Accepted and written into the proofs

| Objection | Who | Resolution |
|---|---|---|
| NFL quantifiers and the orthogonal-correction step | A, B, D | Theorem NFL is restated as two claims that are actually proved: an affine readout can take any value at a fixed cochain, and negating the final head reverses a recomputed response while an intertwiner keeps the residual at zero. The frozen-cochain derivative is not called a `do`-effect. |
| Euclidean descent is not `M`-descent | A | File 09 now separates `-(s-Πs)` from `-∇D`. Both signs are pairings with `∇L`. CE-17 remains the `M=I` case, where they coincide and the obstruction step has the wrong sign. |
| `W'` must be a full congruence | A | File 08 states `W' = A_head^{-T} W A_head^{-1}`, cross terms included. |
| CE-07 metrics are congruent if `s` is transformed too | A | File 08 says so. The ranking reversal is the operation that changes `M` and keeps `s`. |
| Minimum-norm least squares needs a transformed tie-break | A | File 08 withdraws the claim that transformed least squares automatically recovers `ρ'`. |
| Duplicate edges are not ill-conditioned | A | The test now accepts a rank-deficient `d` with a real scale and checks the pseudoinverse against the projection. A duplicate identity edge has `D=1/2` and `O=2`. |
| Idle item 3 lacked quantifiers | A | Items 1 and 2 are the theorem. Item 3 is restricted to a non-constant `q` on a positive-dimensional kernel. |
| Pointwise `J` is not a Lipschitz bound | D, against A's "no error" on this one | Family F withdraws the proof of the printed proposition. `L(t)=1-2t^2` flips sign inside the printed budget. `τO` does not repair that. Where an increment is truly bounded, `τO` is still slack. A's algebraic remark about deleting a nonnegative term is kept for that narrower hypothesis only. |
| Nesting versus overlapping descendants | B | Family H defines `I` only for non-nested clamps with truncation. Overlap alone does not make the map undefined. |
| Addition does not imply `I=0` | B, C | The example `y=(u+w)^2` has `I=2` and aggregation residual `0` on every recomputed world. It is now a test. |
| `I` is not automatically a Hessian | B | The Hessian sentence is withdrawn. |
| Theorem Z is not a Transformer-block theorem | C | File 03 and Family G restrict Z to a fixed map of the intervened argument. Attention, LayerNorm, and an MLP are not constant linear intertwiners. A nonzero shared-linear residual on those maps is approximation error. |
| Geiger and Sutter comparisons were too strong | C, E | "Strictly weaker," "special case," and "avoids the vacuity result" are withdrawn. Commutation and interchange are incomparable. A shared linear `ρ` is outside Sutter et al.'s unrestricted class and is still not a signed predictor. |
| File 07 mixed three notions of identification | B | The file now separates convention dependence, split leakage, and the fact that a fully specified `do` identifies `R_c` by recomputation. The negative claim is that the residual does not determine that sign. |
| Finite-step descent can oppose its own derivative | D | File 09 says the sign criterion is first-order. |

## Not accepted

- Reviewer A found no error in the printed stability inequality. Reviewer D's quadratic is a counterexample to treating `J(h)` as the budget. D's counterexample wins. The manuscript's formula is not adopted.
- No reviewer produced a system in which `(P, ρ, M, W)` alone fixes the sign of a recomputed `R_c` without a readout assumption. The request for a rescue was declined by the review briefs, and none appeared anyway.

## What the disagreement does not license

The reviews leave four objects, the same four as file 06: a commutation residual, a squared distance, an output derivative, and an interaction contrast. Narrowing Theorem Z so that it does not cover attention does not create a fifth object. It says the linear residual on a real block is approximation error. Approximation error is Object 1. It still does not contain `∇L`.
