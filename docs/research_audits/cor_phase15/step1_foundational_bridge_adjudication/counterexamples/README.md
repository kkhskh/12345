# Counterexamples

The witnesses are generated by `proofs/bridge_math.py` and checked by `tests/test_bridge.py`. The register, with the hypotheses each witness meets, is `../COUNTEREXAMPLE_REGISTER.md`.

| Witness | Constructor or test |
|---|---|
| Dilution crossover (D) | `dilution_model(mlp="off" or "random")`; `test_D_dilution_crossover_in_full_prenorm_block` |
| Re-reading MLP reverses the total effect (D′) | `dilution_model(mlp="reverse", mlp_gain=0.5)`; `test_D_downstream_mlp_reverses_the_direct_prediction` |
| Final-LN norm-coupling crossover (LN) | inline in `test_LN_final_norm_coupling_creates_crossover_without_attention` |
| Relation-blind dedicated heads (NEG) | `dedicated_heads_model()`; `test_D_nearby_negative_model_dedicated_heads_is_relation_blind` |
| Double cancellation without crossover | `[[3,6,6.5],[5,7,8],[7,7.5,8.5]]`; `test_RB_double_cancellation_violation_without_crossover` |
| Two flips on a non-monotone null path | `test_NC_two_flips_on_a_non_monotone_path` |
| RMSNorm: no flips | `test_NC_rmsnorm_analogue_never_flips` |
| Same relation, different decision; same decision, different relation | `test_SS_*` |
