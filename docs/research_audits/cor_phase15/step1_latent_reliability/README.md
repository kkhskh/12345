# COR Phase 1.5 Step 1: latent reliability, shared relational computation and causal mechanism discovery

**Start here:** `MAIN_ANSWER.md`. For the preregistered replication of the T4 mechanism, see `REPLICATION_PROTOCOL_T4.md` and `REPLICATION_RESULTS.md`.

Then read, in this order:

| order | file | contents |
|---|---|---|
| 1 | `MATH_VALIDATION.md` | Bayes-level results |
| 2 | `PROTOCOL.md`, `PROTOCOL_ADDENDUM_TAG.md`, `DEVIATIONS.md` | what was frozen, registered or changed, and when |
| 3 | `VERDICTS.md` | generated by `scripts/aggregate.py` |
| 4 | `THEOREM.md` | Bayes, engineered and learned levels, kept separate |
| 5 | `ADJUDICATION.md` and `reviews/` | reviews and dispositions |
| 6 | `FAILURE_MATRIX_UPDATE.md` | COR failure-matrix update |

**Labels.** Post hoc material is labelled POST HOC / [PH] everywhere.

**Reproduction.** Use Python 3.13, jax[cpu], optax, numpy and scipy.

| step | command |
|---|---|
| math checks | `python3 src/math_checks.py`, then `python3 src/math_checks2.py` |
| training | `scripts/train_run.py TASK SIZE SEED STEPS OUTDIR K ARCH` (queue: `logs/train/jobs_main.txt`) |
| analysis | `scripts/analyze_model.py` and `scripts/analyze_tag.py` (dev, then conf), then `scripts/aggregate.py` |
| post hoc | `scripts/posthoc*.py`, `scripts/train_curriculum.py`, `scripts/analyze_deepsets.py` |
| clean extraction | `scripts/verify_extraction.sh PACKAGE.zip` |

**Checkpoints.**

| directory | contents |
|---|---|
| `checkpoints/main` | grid runs |
| `checkpoints/pilot` | seed 100, code checks only |
| `checkpoints/posthoc_*` | post hoc runs |
