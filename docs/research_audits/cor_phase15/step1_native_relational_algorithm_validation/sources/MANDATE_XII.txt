# 3. CENTRAL RESEARCH QUESTION

**What native neural operations construct the relational eligibility computation, how do those operations cause candidate-specific decisions, and which aspects of the computation remain invariant across independently trained models and changed source-generating conditions?**

Investigate competing explanations rather than assuming Investigation XI's preferred interpretation is correct.

### H1 — Shared causal relational algorithm

The trained models implement equivalent relational operations through different neural components, and the identified eligibility representation is a genuine mediator of candidate-specific decisions.

### H2 — Shared abstraction, different downstream algorithms

The models construct an equivalent eligibility representation but differ in how they transform that information into candidate evidence.

### H3 — Intervention-dependent apparent mechanism

The identified pathway or subspace appears causal because of the particular intervention construction, alignment procedure, or restricted evaluation distribution.

### H4 — Redundant or compensating implementations

The measured pathway is important but is not the complete natural mechanism. Alternative pathways, redundant information, or compensating computation contribute to the same decision.

### H5 — Restricted computation with limited structural generalization

The learned relational operation is valid under the training generator but does not implement the appropriate decision transformation under changes in collusion, copying, or source dependence.

These possibilities may overlap.

Develop tests that distinguish them.

# 5. WORKSTREAM B — WEIGHT-LEVEL CAUSAL CIRCUIT RECONSTRUCTION

**Mandatory primary scientific investigation.**

Investigation XI located the conjunction in layer 1 but did not establish the actual weight-level computation.

Go deeper.

## B1. Identify the operations

Examine selected attention heads and MLP components within layers 0–1, including:

- Query and key features.
- Attention-score formation.
- Attention probability changes.
- Value and output projections.
- MLP input directions.
- Nonlinear activation behavior.
- Residual interactions.
- Normalization effects.
- Downstream readout contributions.

Determine how the network combines perfectness information with target-question agreement.

Is the relevant computation implemented through a thresholded operation, a smooth multiplicative interaction, attention selection, or another mechanism?

Do not infer the answer from output correlations.

## B2. Establish the actual causal pathway

Use path-specific interventions to determine which components transmit, construct, or use relational information.

Attempt to establish a mechanism of the form:

**Source relationships → internal relational operation → eligibility representation → candidate-evidence weighting → final decision.**

At each link distinguish:

- Information availability.
- Correlation.
- Decodability.
- Causal transmission.
- Computation.
- Mediation.
- Downstream use.

A component that carries an already computed interaction is not necessarily the component that constructs it.

Seek both necessity and restoration evidence, while stating the assumptions required for those conclusions.

## B3. Challenge the previous ablation

Investigation XI removed the measured interaction using an additive-completion intervention.

This can produce hybrid activations that are not naturally generated by the model.

Repeat the mechanistic assessment using alternative intervention constructions, such as:

- Matched activation resampling.
- Mean-based interventions.
- Path-specific patching.
- Controlled component replacement.
- Valid input-level counterfactuals.
- Alternative mediation or causal-scrubbing controls.

Determine whether the reported layer-1 mechanism survives reasonable changes in intervention methodology.

An explanation that works only for one carefully engineered ablation is weaker than an explanation that survives multiple independent intervention designs.

## B4. Compensation and redundancy

Test whether the network possesses alternative routes that become apparent when individual components are removed.

Use single-component and joint-component interventions.

Check whether apparent restoration can be explained by residual information, redundant heads, alternate MLP directions, or downstream recomputation.

Distinguish immediate compensatory routing within a fixed forward computation from adaptation that would require retraining.

Do not infer that no backup exists merely because one ablation failed to reveal it.

Where complete identification is impossible, establish quantitative bounds or meaningful restrictions.

## B5. Explain learning dynamics

Investigation XI observed that the relational representation appears before the model adopts the correct candidate-decision rule.

Use saved checkpoints to investigate whether this delay results from:

- Downstream readout learning.
- Insufficient magnitude of the representation.
- Competition with earlier heuristics.
- Changes in attention routing.
- Optimization dynamics.
- Other mechanisms supported by the evidence.

Try to predict the behavioral transition from an internal measurement that is not simply the final output.

This would provide a stronger learning-mechanism result than observing the order alone.
