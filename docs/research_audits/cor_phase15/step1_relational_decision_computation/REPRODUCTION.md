# Reproduction (Investigation XIII)

## Not standalone

The archive holds this package only: `step1_relational_decision_computation/`. It must be extracted next to the sibling `cor_phase15`
packages it depends on, which are listed in `logs/DEPENDENCIES.json` → `sibling_packages_required`. Those packages provide:
- `step1_native_relational_algorithm_validation` (XII): vP150–156 parents and fine-tunes, DAS E-subspaces, the XII code base copied
  into `src/`;
- `step1_causal_equivalence` (X) and earlier packages: xP81, yP13x and wP14x checkpoints, and the development evaluation set.

All 277 external data files are pinned by sha256 in `logs/DEPENDENCIES.json`. The fresh cohort (uP160–165: parents, gates and
fine-tunes) is **inside** this package and is covered by `MANIFEST.sha256`.

## Environment

Python 3, jax/jaxlib, numpy, optax, scikit-learn and scipy; exact versions are in `logs/DEPENDENCIES.json`. Use
`XLA_FLAGS="--xla_cpu_multi_thread_eigen=false intra_op_parallelism_threads=1"`. Everything runs on CPU; 2 CPUs were used.

## Pipeline

1. **Stage 0.** `scripts/pretrain_gated.sh <seed>` for seeds 160–165 (queues `logs/queue_pre_*.txt`).
2. **Prediction freeze.** `logs/predictions_xiii.json`, `scripts/score_xiii.py` and `scripts/preflight_nulls.py`; hashes in
   `logs/FREEZE_XIII_HASHES.txt` (commit 47506c3).
3. **Fine-tunes.** `scripts/native_train.py uP<seed> full_c1 4000 20 label logs/eval_conf13.npz` (queues `logs/queue_train_T*.txt`).
4. **Confirmation analyses.** `logs/queue_conf_C*.txt`, generated by `scripts/make_conf_queues.py`. Each queue line can be run directly
   from the package root, or through `scripts/lane.sh`.
5. **Merge and score.** `scripts/conf_merge.sh` → `logs/score_xiii.json`. Then `scripts/report_xiii.py` (R1–R4) and
   `scripts/stats_xiii.py`.
6. **Mathematics.** `scripts/verify_shared_posterior.py` and `scripts/sufficiency_boundary.py`.
7. **Exploratory.** `scripts/transition_predictor.py` (TP_MODELS=…).
8. **Archive check.** `scripts/verify_clean13.sh ZIP COR_PHASE15_ROOT LOG`. Ten steps; the result is in `logs/VERIFY_CLEAN.txt`.

Development runs used the same scripts with the `_dev*` tags shown in `logs/COMPUTE_LOG.txt`.
