# Investigation XVII: frozen protocol (the preregistration record)

This file is committed with the freeze, before any fresh confirmation model is trained. The hashed implementation is listed in `logs/FREEZE_XVII_HASHES.txt` (27 files).

**Status.** COR Phase 1.5, Step 1, provisional ≈ 25%, unchanged. O/D is silent on this question (ORIGINAL_COR_OD_AND_POSITIONAL_REUSE.md, committed `431b1b6` before any neural result), so no O/D prediction is frozen.

## 1. Development (existing XVI models only; not confirmation)

- **Models:** C_s202, WB_low_s503 and WA_const_s402, regenerated by bitwise-exact deterministic replay (XVI).
- **Analyses:** per-slot reconstruction, identity-relabel windows, attention-routing transplants, code interpolation, and slot-targeted training.
- **Results:** COMPETING_NEURAL_MECHANISMS.md §3 and `logs/expl/`.
- **Diagnostic stream:** 99_800_000, disjoint from XVI's inline stream. The confirmation analysis uses the same measurement code.

## 2. Confirmation cohorts (logs/XVII_design.json)

| cohort | condition | recipe | steps | inline diagnostics | seeds |
|---|---|---|---|---|---|
| arity 3 | 3:0.9:0.9:1/3 (condition C) | XVI constant rate (warm-up 200, 1e-3) | 5000 | every 50 | 801–804 |
| arity 2 | 2:0.9:0.9:0.05 (XV's A, XVI's WB-high) | XV cosine | 4000 | every 25 | 701–708 |

- **Independence:** 12 fresh, independent initialisations with independent data streams. Six slots per model are not six replications. Analysis pairs within a model are not independent.
- **Training:** `scripts/xvii_train.py` (XVI trainer plus parameter snapshots every 20 steps), BLIND = 1.
- **Analysis:** after each run, `scripts/xvii_confirm_analysis.py` (window, per-slot reconstruction, partial-checkpoint selection, battery, late battery) writes `logs/analysis/<run>.json`.
- **Learning arms:** after all analyses, `scripts/xvii_learning_arm.py` runs for the subset (every evaluable arity-3 model and the first two evaluable arity-2 models): 400 steps, targeted against full.
- **Execution:** everything runs from `logs/queue_xvii.txt` on two lanes.
- **Integrity rule (lesson from XVI's review):** no output file of any confirmation run, analysis or learning arm is opened before `score_XVII.py` runs. That includes line counts. Progress is monitored only from the lane log (start, end, exit code) and from the existence of `done.json` and analysis files.

The primary verdicts are pooled across arities, and per-arity verdicts are reported.
