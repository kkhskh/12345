# 4. TRACK B — ARE THERE REALLY DIFFERENT ALGORITHMS?

**This track is as important as Track A.**

XIX found that the behavioral differences between organizations may primarily reflect different precision in approximating the same Bayesian decision.

This must be confronted directly.

Do not assume the early and mixture organizations implement different algorithms merely because previous COR investigations used those labels.

## B1. Formalize the candidate decision procedures

Reconstruct the exact T4 Bayesian rule.

Reconstruct the behavioral models previously used to describe early and mixture organizations.

Determine:

- Which functions are mathematically equivalent.
- Which are distinct only by calibration.
- Which differ in posterior combination.
- Which differ only on off-support inputs.
- Which predict genuinely different decisions on valid inputs.
- Which fitted parameters are non-identifiable.

Earlier investigations showed that fitted power-mean operators are not unique neural descriptions.

Do not use a good formula fit as proof of a neural operation.

## B2. Derive discriminating test inputs

Construct mathematically valid examples where the proposed alternative computations make different predictions.

Prioritize input cases that preserve the generator's meaningful support.

Use carefully defined changes in:

- Source reliability.
- Within-group agreement.
- Cross-question relational evidence.
- Source copying or dependence.
- Evidence conflicts.
- Candidate posterior margins.

Do not introduce arbitrary off-support probes and claim they reveal the natural algorithm.

If off-support testing is useful, label it explicitly and evaluate whether the result is identifiable from the training distribution.

## B3. Distinguish functional differences from precision

Measure:

- Accuracy.
- Negative log-likelihood.
- Calibration.
- Bayes regret.
- Counterfactual decision changes.
- Posterior ranking.
- Candidate-specific response.
- Differences after matched output calibration.
- Residual differences after accounting for lapse and noise.

A noisier approximation of the same rule must not be classified as a distinct algorithm.

## B4. Test internal computations

Use causal interventions to determine whether different neural routes implement:

- The same sufficient relational statistic.
- Different approximations of the same statistic.
- Different evidence-combination functions.
- Different conditional decision procedures.

Where feasible, test whether an internal computational variable transfers between organizations.

Require appropriate source-matched and ideal-reference controls.

A successful activation interchange must not be mistaken for algorithm identity.

Likewise, differences in attention-head necessity alone must not be mistaken for algorithm differences.

## B5. Competing scientific claims

Track B must distinguish three outcomes.

**B1 — Different algorithms**

The organizations implement distinguishable decision computations, supported by independent functional predictions and causal evidence.

**B2 — Same algorithm, different implementations**

The organizations approximate the same mathematical rule using different internal pathways.

**B3 — Same rule, different precision**

The observed differences primarily reflect approximation quality, calibration, or noise.

A fourth outcome, non-identifiability, is acceptable.

The confirmation experiments must be designed to distinguish these outcomes.

**If no mathematically valid input can distinguish the candidate algorithms, establish that limitation before expensive training.**

Do not spend GPU hours merely confirming that two models have different attention patterns.
