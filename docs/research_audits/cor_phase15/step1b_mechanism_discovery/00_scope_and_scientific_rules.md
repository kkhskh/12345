## What is rejected, and what is open

Rejected as universal claims, by Step 1A counterexamples that this step reproduces:

- `ΔD < 0 ⇒ ΔL > 0`
- `D_c < D_{c'} ⇒ L_c > L_{c'}`
- A quadratic residual is automatically a causal mechanism
- An exact coboundary is a nontrivial cohomology class

Open, and investigated here rather than declared false:

- Whether some independently identified relationship among computational components constrains a causal response beyond local magnitude, ordinary sensitivity, or attribution
- Whether that relationship, if it exists, is a scalar, a vector, an operator, a subspace, or a restricted intervention family
- Whether Transformers implement error correction, compensation, or competing-evidence aggregation in a form that would show up as a distinctive signature

## Evidence labels

`PROVED`, `PROVED_UNDER_RESTRICTED_ASSUMPTIONS`, `DISPROVED`, `COUNTEREXAMPLE_FOUND`, `CONJECTURE`, `UNIDENTIFIED`, `EMPIRICALLY_UNTESTED`, `REDUNDANT_WITH_EXISTING_THEORY`, `UNRESOLVED`, `OUTSIDE_SCOPE`.

A synthetic test that passes is not `PROVED` unless it checks a stated identity. Failure to find a random counterexample is not a theorem.
