# 13 — Family G: competing evidence versus transport disagreement

Two probes reporting different labels is a representational disagreement. It is not a statement that the network compares those probes. It is not `ρ s_u - s_v`.

A causal competition would be: two internal variables `e_1`, `e_2` both enter an aggregator whose output is `L`, with opposite typical signs of `∂L/∂e_i`. Measuring that is mediation. Common coordinates are required only if one wants a scalar "disagreement" in one space; the causal claim does not need that scalar.

They can disagree while `L` is correct (one path is unused). They can agree while `L` is wrong (both carry the same error). A conflict statistic can track uncertainty only if it tracks something like `|e_1-e_2|` that the aggregator actually uses as a gate. No such gate is identified from the architecture alone.

**Status.** The interesting object is competing causal parents of `L`. That is mediation. Probe disagreement is `EMPIRICALLY_UNTESTED` as a proxy and is not assumed. `UNIDENTIFIED` as a COR conflict energy.
