# 18 — Formalisms, after the phenomena

Order used: phenomenon, then assumptions, then notation.

| Tool | Where it earned a theorem here | Where it was not used |
|---|---|---|
| Linear algebra | N1, N2, path contributions, kernels | — |
| SCMs with truncation | Nested `do`, `I` | — |
| Ordinary calculus | Hessians of linear versus square maps | — |
| Lipschitz / perturbation | Stability bound | Pointwise Jacobian as a false substitute |
| Causal abstraction | Sufficiency language | Not re-derived |
| Information theory | Not used as a causal proof | Mutual information would not have identified use |
| Sheaf cohomology | Not used | `[ds]=0` remains the Step 1A correction; no new complex |
| Category theory | Not used | Function composition was enough for Theorem Z |
| Constrained optimization | Not used | Would recreate `min D` |
| Energy / dynamics | Not used | No iteration in the block |

No formalism was adopted because it was available. Cohomology stays out: there is still no genuine extension obstruction in a globally defined 0-cochain of this architecture.
