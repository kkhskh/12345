# 22 — Surviving mechanism candidates

The ten-point bar in the assignment is an evaluation standard. Nothing in this directory meets it as a distinctive causal mechanism for a relational score.

## What survives as mathematics

| object | what it is | why it is not a candidate for further COR development |
|---|---|---|
| Fiber constancy | the definition of exact sufficiency | It says when a summary determines a response. It does not exhibit a new summary |
| N1 | fiber constancy on a two-orientation kernel | A blindness constraint. It does not propose a predictor |
| Separability iff identically zero interaction | calculus on a rectangle | It tells an experimenter when a measured zero is about the pair and when it is about the function. It is not a pathway relation |
| `Y=AVW_O` under a clamped pattern | QK/OV linearity | The Jacobian of that intervention. A consistency residual is not an input |
| `O` independent of `M` | the formula | A correction, not a mechanism |
| LayerNorm sign, with the orthogonal-`w` exception | the normalization formula | It blocks a false invariance. The exception is an inner product |
| Recomputed residual identically zero | the definition of recomputation | Vacuous as a predictor on that family |

## What does not survive

A coboundary of projected states, a quadratic `O` or `D`, an arbitrary or one-point `\rho`, vector agreement, and "shared nonlinearity" as a universal interaction. Each fails at least one of: independent identification, a consequence for a named intervention that the Jacobian or the path effect does not already give, or a counterexample under its own stated hypotheses.

## The bar, applied once

No object here has a computational variable the block multiplies, a nontrivial structural condition that is not already the block's equation, an identification that avoids `R`, and a consequence that is not the Jacobian, the Hessian, the path effect, or fiber constancy. The value-linearity law has the computational definition and the consequence, and it fails distinctiveness. Recording it again under another name would not be a deeper theory.

The open classes in `19` are unresolved. Unresolved is not a candidate. A candidate would be a restriction written down far enough that a counterexample can be attempted. That writing was not earned by any relational score in the examined classes.
