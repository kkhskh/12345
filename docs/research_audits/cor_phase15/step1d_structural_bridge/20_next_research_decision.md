# 20. Next research decision

Phase 2 is not opened. `OBSTRUCTION_READY` stays `NO`. `COR_PHASE1_CONDITIONAL_THEORY_REPAIR_REQUIRED` stays in force.

The decision this package supports is narrower than a new program. The overnight impossibility claim about weight-informed directional bounds is withdrawn. In its place there is an explicit Regime 1 bound, a scale threshold, an output-kernel identity, and a negative answer for three joint-path candidates. A later project that wants a relational theorem has to exhibit `Q` and a proof of `B_joint < B_align` under a named regime, or it has to shrink the admissible increment set by a coupling estimate that is not the Lipschitz radius already used. Until that exists, there is no frozen hypothesis to run on a sealed set, and no reason to refit Direction 1.

Work that would be a different project, not a continuation of this bound: stacks, post-norm, a proved segment-minimum for `s`, and a Regime 1 coupling estimate below the product-ball maximum. Each of those can be attempted without pretrained models and without Phase 2. None of them is promised by this directory.

If a frozen Transformer is ever inspected for `||W_O w||` and `||W2.T w||`, that inspection is a gain calculation. It should be authorized separately, it should not be fit to evaluation responses, and a small gain should be reported as a small gain.
