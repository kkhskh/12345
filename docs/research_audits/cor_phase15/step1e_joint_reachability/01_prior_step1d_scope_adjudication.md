# 1. What Step 1D established, and what it did not

Step 1D's verdict `STEP1D_STRUCTURAL_CERTIFICATES_ONLY` stands. This package does not reopen it.

The part that matters here is the joint-path negative result. Step 1D compared pathway increments inside independent norm balls. On that product, the maximum of a separable linear readout is the sum of the separate maxima. That ceiling is sharp for the product. It is silent about pairs `(a(δ), b(δ))` that a single δ can actually produce.

Three sets have to stay apart.

- Set A is the image `{(a(δ), b(δ)) : δ ∈ U}` of one frozen block.
- Set B is the product of the exact marginal images.
- Set C is a product of norm-ball outer bounds. Step 1D's R2 ceiling is a Set C statement.

A bound that is optimal on Set C need not be optimal on Set B, and a bound that is optimal on Set B need not be optimal on Set A. The product-ball theorem is not a theorem about the Transformer. It remains true, and it is not reused below as a characterization of the block.

The other Step 1D limits that this step keeps are local. Cancellation of the two branch derivatives at the base point does not cancel the finite response. A skip-only surrogate has an error controlled by the branch size; that error bound is not a joint improvement. None of those statements is rewritten.
